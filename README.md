Solano Heat is an original 2D top-down open-world crime game (GTA 1/2 style) set in the city of Port Solano. Drive and steal cars, outrun the police across a 5-star wanted system, take taxi fares, hunt 20 hidden packages, and run 6 story missions for Rico — all in vanilla JavaScript and Canvas 2D, with procedural art and synthesized WebAudio sound. No libraries, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts --port 8080
```

Then open http://localhost:8080 in a desktop browser. Keyboard to drive and walk, mouse for menus.
